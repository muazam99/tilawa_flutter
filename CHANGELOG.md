## 0.1.0-dev.1

* Initial development SDK for offline Tilawa recognition and word tracking.
* Typed session events, bounded external PCM input and optional microphone capture.
* Verified local, bundled and downloaded recognition assets.
* Optional corpus-compatible display metadata and standalone Flutter example.
* Android native ONNX inference with retained recurrent tensors and the pinned
  matching core in a QuickJS worker. Runtime identity and JNI R8 rules are packaged.
* MIT license for authored integration, with separate third-party/asset terms.
* Android device checkpoints recorded; iPhone verification and runtime/resource
  acceptance remain pending. This version is not a publication candidate.
